## Новые прогоны

Предпочтительный запуск (Python 3.11+, бинарник предварительно собран):

```powershell
python simulation/scripts/run_fuzz.py --binary C:\path\to\fuzz_pool.exe --results-root C:\Users\a1ole\OneDrive\tonGraph\runs -- -max_total_time=3600
```

В Linux/WSL укажите Linux-бинарник и доступный путь к OneDrive через
`--results-root` либо `TON_FUZZ_RESULTS`. Не запускайте Windows-бинарник как
замену Linux-сборке. `--seed-corpus PATH` копирует исходный корпус в отдельный
каталог прогона, сохраняя архив неизменным. `--dry-run` создаёт структуру и
манифест, но не запускает фаззер.

Каждый прогон получает `corpus/`, `crashes/`, `fuzzer.log`, `run.json` с commit,
признаком незакоммиченных изменений, командой и хешем бинарника. Рабочий каталог,
GraphLogger и LLVM profiles также направлены в каталог прогона. Перед серией
экспериментов используйте чистую рабочую копию; сохраняйте параметры сборки рядом
с результатами. SHA бинарника и commit сами по себе не фиксируют toolchain.

Генерация стартового корпуса модели:

```powershell
python simulation/scripts/gen_targeted_corpus.py --output C:\Users\a1ole\OneDrive\tonGraph\generated\model-seeds
```

Старые `run_fuzz_p5*.sh`, скрипты rsync и команды в документах сохранены как
исторические рецепты для конкретных машин; они используют старые пути внутри
checkout. Для новых запусков используйте `run_fuzz.py`.
